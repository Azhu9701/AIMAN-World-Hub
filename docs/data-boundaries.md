# 数据与能力边界

[返回首页](../README.md) · [官网方法说明](https://www.aiman.world/methodology)

## 一套数据，多种入口

网页、REST 与 MCP 是公开读模型的不同入口。本仓库提供介绍、截图和接入说明，不维护另一份正式产品数据库，也不承担事实审核。

`AIMAN.World` 是母品牌；`Robotics World` 是当前机器人产业领域；`聚身之家` 是它的中文产品名与公开入口。

## 读取到资料，不等于完成核验

- 产品描述、厂商自述、参数记录、已核验能力和正式断言的状态可能不同，应保留返回的来源与审核字段。
- 企业目录的产业角色、产品原产地和国家投影，不能自动当成工厂、部署现场或销售地区。
- `/graph` 与企业资料关系保留收录主张；`world.graph` 读取 Canonical World 关系。两个投影的数量不必相同，资料连线不自动提升为正式事实。
- 一个 Evidence UUID 存在，不保证其详情公开。无权访问、不公开或不存在的材料可能返回 404。
- 部件数据库的收录地图不是每台机器人的完整 BOM；`compatible` 不代表实际安装。
- 页面价格是目录记录或询价入口，不是实时成交价、库存或交付承诺。

## 时间与未知

事件发生时间、文章来源日期、收录时间、更新时间和核验时间不能混用。截图日期只记录拍摄时间；宣传片日期未知，不以导出时间冒充拍摄日期。

时间线里的未来假设不是事实，也不是已经发生的事件。缺少能力记录不是已证明不具备该能力；查询失败与成功但结果为空也需要分开。

机器人演示、订单、试运行、部署和量产是不同状态。部署成功不能直接证明人的工时、负荷、安全、工资、技能或工作内容已改善。

## 已有入口与仍在完善的能力

当前可发现机器人、企业、零部件、状态、关系、事件、证据、展会观察和文章的公开读取工具。发现工具不保证每个实体都有完整数据。

完整工厂产能、实时订单交付、完整供应链、统一不可变历史快照、广泛核验的部署覆盖与任务匹配，不在本仓库中宣称已完成。Beta 的世界地图、劳动与部署、具身数据交易、IP 工程与授权等功能，以各页当前说明为准。

## 贡献与正式更新

公开 Agent 提交的是待审观察材料，`canonicalWrites=false`。提交成功、收到 receipt 或 HTTP 200，都不等于正式事实已更新。身份匹配、证据判断、审核与读回仍是后续环节。
